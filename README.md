# Τράπεζα θεμάτων downloader

## dependencies
- python > 3.0
- pypdf

## χρήση
```
usage: thema downloader [-h] [-s] [-d] [-o OUTPUTFILE] [files ...]

positional arguments:
  files

options:
  -h, --help            show this help message and exit
  -s, --solutions       query for solutions too
  -d, --download        download instead of opening tdf
  -o, --outputFile OUTPUTFILE
                        specify an output name

```
